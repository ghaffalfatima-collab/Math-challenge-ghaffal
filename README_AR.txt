Math Challenge 3AC — مشروع Android أولي

المحتوى الحالي: لعبة الجذور التربيعية فقط، مع صفحة رئيسية لدروس ستضاف لاحقًا.

خطوات إنشاء APK و AAB:
1. فك الضغط وافتح المجلد في Android Studio (Open).
2. انتظر Gradle Sync (يتطلب إنترنت لتنزيل الأدوات أول مرة).
3. جرّب اللعبة على هاتف أو محاكي: Run.
4. لإنشاء APK تجريبي: Build > Build APK(s).
5. للنشر: Build > Generate Signed Bundle / APK > Android App Bundle.
6. جهز حساب Play Console وبيانات التطبيق وسياسة الخصوصية والاختبارات المطلوبة.

تنبيه: هذا مشروع مصدر قابل للبناء، وليس APK أو AAB جاهزًا. لم يتم اختباره على جهاز Android في هذه البيئة.
قبل النشر: اختبر الأسئلة الرياضية والأصوات، وصمم أيقونة للتطبيق، وحدد سياسة الخصوصية والفئة العمرية المناسبة.
